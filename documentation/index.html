1. Template Overview

Little Chefs Academy is a fun, hands-on, highly responsive website template tailored for kids cooking schools, culinary camps, family baking workshops, and youth nutrition programs. It features light & dark mode toggles, full RTL (Right-to-Left) Arabic/Hebrew support, WCAG 2.1 AA accessibility standards, skeleton loaders, and an interactive parent dashboard.

2. Installation & Quick Start Guide

No build step or Node.js required! The template uses vanilla HTML5, CSS3, ES6 JavaScript, Bootstrap 5.3, and Tailwind CSS utilities.

Step 1: Open with Any Web Server or Live Server

You can serve the directory using VS Code Live Server, Python simple HTTP server, or any Apache/Nginx web server:

# Using Python 3 built-in HTTP server: python -m http.server 8000 # Open in browser: http://localhost:8000/

3. Customization Guide

3.1 Color Palette (CSS Variables)

To customize brand colors, open assets/css/style.css and update the root tokens:

:root { --color-primary: #FF5E36; /* Main Brand Tangerine */ --color-primary-hover: #E04822; --color-secondary: #10B981; /* Fresh Herb Mint */ --color-accent-gold: #FFB703; /* Honey Dijon */ --color-accent-purple: #8B5CF6; /* Berry Purple */ }
3.2 Typography

Headings use Google Font 'Fredoka' and body copy uses 'Plus Jakarta Sans'.

4. Key Built-in Features

  • Dark / Light Mode Switching: Instant theme toggle with local storage persistence and system auto-detection.
  • Full RTL Support: Complete dir="rtl" layout mirroring for Arabic and Hebrew text.
  • Interactive Cook-Along Timer: Real-time start, pause, and reset timer widget for recipes.
  • Client-Side Live Validation: Built-in validation with animated feedback and toast alerts.
  • Skeleton Loaders: Interactive toggle to preview skeleton placeholder states.

6. Parent Dashboard Architecture

The parent portal in pages/dashboard.html and assets/js/dashboard.js provides:

  • Child Profile Management: Add and view enrolled kids, record severe allergies and dietary flags (Peanut-free, Gluten-free, etc.), and view earned badges.
  • Live Session Enrollment: Select child, choose upcoming class or camp session, and complete simulated checkout with Stripe/Apple Pay.
  • Schedule & Attendance Tracking: Interactive schedule table with calendar export (iCal/Google Calendar format simulation) and session rescheduling.
  • Session Photo Albums: High-res photo albums with lightbox zoom and download button.
  • Digital Recipe Vault: Print-ready family recipe cards for at-home cooking.
